# Example: writing guide

> Synthetic skill. It exists in **two** skill roots with **different content**, so
> the example run has a real divergent mirror to report.

## Style

- Lead with the outcome, then the detail.
- One recommendation, not a survey of options.
- Keep an explicit constraint from the user in force for the whole session.

## Structure

- Short sections with names, never numbers: a numbered heading shifts when a
  section is inserted and every cross-reference silently points at the wrong
  content.
