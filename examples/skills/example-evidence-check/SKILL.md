# Example: evidence check

> This is a **synthetic skill** shipped so that `asi daily` has something to read
> on a fresh clone. It is intentionally incomplete, because the offline example
> demonstrates a proposal that fills one specific gap in it.

## When to use

Use this when a task turns on a claim about the world: what a file contains, what
a command returned, what another team's process is.

## What to do

- Prefer a measurement over a recollection.
- If a claim cannot be checked, label it as an assumption rather than stating it
  in the grammar of an observation.
- When two sources disagree, name both and say which one you are trusting.

## What not to do

- Do not present an inference as an observation.
- Do not describe a file you have not opened.
